## Plugin Credential files

Vectorworks 2026 introduces the requirement for script plugins that are encrypted/obfuscated and SDK plugins to have a satellite credentials file that defines who is the developer of the plugins is.

Vecotrworks 2027 uses the same [Plugin Credentials](Common/Tasks/Info/PluginCredentials.md) files, so you can reuse the ones from Vectorworks 2026 or request one. See the article [Plugin Credentials](Common/Tasks/Info/PluginCredentials.md).
