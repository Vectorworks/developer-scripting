# HP_IsLoadObject

## Description
Returns TRUE if the handle is a load object (has load data).

```pascal
FUNCTION HP_IsLoadObject(handle : HANDLE) : BOOLEAN;
```

```python
def vs.HP_IsLoadObject(handle):
    return BOOLEAN
```
