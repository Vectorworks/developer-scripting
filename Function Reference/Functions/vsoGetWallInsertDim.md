# vsoGetWallInsertDim

## Description
Gets the Wall Insert message information for the dimension inserting height for this object for parametric event 107. Call vsoSetWallInsertDim to return the height.

```pascal
FUNCTION vsoGetWallInsertDim(
				VAR outDim1X : REAL;
				VAR outDim1X : REAL;
				VAR outDim2X : REAL) : REAL;
```

```python
def vs.vsoGetWallInsertDim():
    return (REAL, outDim1X, outDim1X, outDim2X)
```

|outDim1X|REAL||
