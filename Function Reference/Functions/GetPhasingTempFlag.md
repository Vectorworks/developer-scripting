# GetPhasingTempFlag

## Description
Function GetPhasingTempFlag takes in a handle and returns the value of the handle's temporary flag for Phasing.

```pascal
FUNCTION GetPhasingTempFlag(hObject : HANDLE) : BOOLEAN;
```

```python
def vs.GetPhasingTempFlag(hObject):
    return BOOLEAN
```

## Parameters
|Name|Type|Description|
|---|---|---|
|hObject|HANDLE|The handle to retrieve the temporary flag value for.|
