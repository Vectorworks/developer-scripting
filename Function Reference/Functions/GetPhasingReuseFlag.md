# GetPhasingReuseFlag

## Description
Function GetPhasingReuseFlag takes in a handle and returns the value of the handle's reuse flag for Phasing.

```pascal
FUNCTION GetPhasingReuseFlag(hObject : HANDLE) : BOOLEAN;
```

```python
def vs.GetPhasingReuseFlag(hObject):
    return BOOLEAN
```

## Parameters
|Name|Type|Description|
|---|---|---|
|hObject|HANDLE|The handle to retrieve the temporary flag value for.|
