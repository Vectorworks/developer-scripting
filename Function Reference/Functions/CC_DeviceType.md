# CC_DeviceType

## Description
Creates a device type symbol definition from a Generic or a DA device and saves the device data to the device database. Returns the handle of the created symbol definition.

```pascal
FUNCTION CC_DeviceType(hDevice : HANDLE) : HANDLE;
```

```python
def vs.CC_DeviceType(hDevice):
    return HANDLE
```

## Parameters
|Name|Type|Description|
|---|---|---|
|hDevice|HANDLE||
