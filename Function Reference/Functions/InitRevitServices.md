# InitRevitServices

## Description
Init Revit Library services for Import and Export

```pascal
PROCEDURE InitRevitServices;
```

```python
def vs.InitRevitServices():
    return None
```

## Examples
```pascal
InitRevitServices;
```
```python
import vs

# Init Revit Library services for Import and Export.
vs.InitRevitServices()
```

Availability: from Vectorworks 2017
