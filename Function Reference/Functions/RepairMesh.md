# RepairMesh

## Description
Repair potentially invalid mesh. Returns a Group containing repaired mesh objects.

```pascal
FUNCTION RepairMesh(meshObj : HANDLE) : HANDLE;
```

```python
def vs.RepairMesh(meshObj):
    return HANDLE
```

## Parameters
|Name|Type|Description|
|---|---|---|
|meshObj|HANDLE|Handle on the mesh to repair|

## Version
Availability: from Vectorworks 2027
