# GetPhaseDescription

## Description
Function GetPhaseDescription takes in a PhaseReference (long) and returns a string indicating the description of the passed in phase.

```pascal
FUNCTION GetPhaseDescription(phaseRef : LONGINT) : STRING;
```

```python
def vs.GetPhaseDescription(phaseRef):
    return STRING
```

## Parameters
|Name|Type|Description|
|---|---|---|
|phaseRef|LONGINT|The phase to retrieve the description for.|
