# GetFCKeystoneMat

## Description
Gets backlit flag from handle

```pascal
PROCEDURE GetFCKeystoneMat(
				topLeft             : REAL;
				topRight            : REAL;
				botLeft             : REAL;
				botRight            : REAL;
				VAR outKeystoneRow0 : VECTOR;
				VAR outKeystoneRow1 : VECTOR;
				VAR outKeystoneRow2 : VECTOR);
```

```python
def vs.GetFCKeystoneMat(topLeft, topRight, botLeft, botRight):
```
