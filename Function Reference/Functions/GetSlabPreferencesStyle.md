# GetSlabPreferencesStyle

## Description
Gets the Slab Style of the Slab Preferences.

```pascal
FUNCTION GetSlabPreferencesStyle : LONGINT;
```

```python
def vs.GetSlabPreferencesStyle():
    return LONGINT
```

resultN := GetSlabPreferencesStyle;
