# GetVKeystoneMat

## Description
Gets backlit flag from handle

```pascal
PROCEDURE GetVKeystoneMat(
				inVKeystone         : REAL;
				VAR outKeystoneRow0 : VECTOR;
				VAR outKeystoneRow1 : VECTOR;
				VAR outKeystoneRow2 : VECTOR);
```

```python
def vs.GetVKeystoneMat(inVKeystone):
    return (outKeystoneRow0, outKeystoneRow1, outKeystoneRow2)
```
