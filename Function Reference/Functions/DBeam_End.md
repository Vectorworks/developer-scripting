# DBeam_End

## Description
End drawing beam routine and create the beam.

```pascal
PROCEDURE DBeam_End;
```

```python
def vs.DBeam_End():
    return None
```

## Examples
```pascal
DBeam_End;
```

```python
vs.DBeam_End()
```
