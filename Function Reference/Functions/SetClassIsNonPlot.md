# SetClassIsNonPlot

## Description
Sets the non-plot attribute of the specified class.

```pascal
PROCEDURE SetClassIsNonPlot(
				classObj  : HANDLE;
				isNonPlot : BOOLEAN);
```

```python
def vs.SetClassIsNonPlot(classObj, isNonPlot):
    return None
```

## Parameters
|Name|Type|Description|
|---|---|---|
|classObj|HANDLE|Handle of the class.|
|isNonPlot|BOOLEAN|isNonPlot controls the non-plot attribute of the class.|

## Remarks
Sets the non-plot attribute of the specified class.

Availability: from Vectorworks 2027
