# GetPhaseName

## Description
Function GetPhaseName takes in a PhaseReference (long) and returns a string indicating the name of the passed in phase.

```pascal
FUNCTION GetPhaseName(phaseRef : LONGINT) : STRING;
```

```python
def vs.GetPhaseName(phaseRef):
    return STRING
```

## Parameters
|Name|Type|Description|
|---|---|---|
|phaseRef|LONGINT|The phase to retrieve the name for.|
