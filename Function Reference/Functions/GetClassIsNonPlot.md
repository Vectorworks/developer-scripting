# GetClassIsNonPlot

## Description
Gets the non-plot attribute of the specified class.

```pascal
FUNCTION GetClassIsNonPlot(classObj : HANDLE) : BOOLEAN;
```

```python
def vs.GetClassIsNonPlot(classObj):
    return BOOLEAN
```

## Parameters
|Name|Type|Description|

|classObj|HANDLE|Handle of the class.|

Gets the non-plot attribute of the specified class.
