# GetUseWallCutPlane

## Description
Gets the use wall cut plane setting of a symbol definition, plug-in object style, or plug-in object.

```pascal
FUNCTION GetUseWallCutPlane(hObject : HANDLE) : BOOLEAN;
```

```python
def vs.GetUseWallCutPlane(hObject):
    return BOOLEAN
```

## Parameters
|Name|Type|Description|
|---|---|---|
|hObject|HANDLE|The symbol definition, plug-in object style, or plug-in object.|

## Returns
The use wall cut plane setting of the symbol definition, plug-in object style, or plug-in object.
