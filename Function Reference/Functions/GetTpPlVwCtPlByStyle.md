# GetTpPlVwCtPlByStyle

## Description
Gets whether the Top/Plan view cut plane of a symbol definition, plug-in object style, or plug-in object is by style.

```pascal
FUNCTION GetTpPlVwCtPlByStyle(hObject : HANDLE) : BOOLEAN;
```

```python
def vs.GetTpPlVwCtPlByStyle(hObject):
    return BOOLEAN
```

## Parameters
|Name|Type|Description|
|---|---|---|
|hObject|HANDLE|The symbol definition, plug-in object style, or plug-in object.|

## Returns
Whether the Top/Plan view cut plane of a symbol definition, plug-in object style, or plug-in object is by style.
