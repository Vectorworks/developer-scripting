# CC_UpdateDeviceType

## Description
Updates the device type symbol with the current data from the given device. Returns the handle of the updated symbol definition.

```pascal
FUNCTION CC_UpdateDeviceType(
				hSymbol : HANDLE;
				hDevice : HANDLE) : BOOLEAN;
```

    return BOOLEAN
