# GetUseWllCtPlByStyle

## Description
Gets whether the use wall cut plane setting of a symbol definition, plug-in object style, or plug-in object is by style.

```pascal
FUNCTION GetUseWllCtPlByStyle(hObject : HANDLE) : BOOLEAN;
```

```python
def vs.GetUseWllCtPlByStyle(hObject):
    return BOOLEAN
```

## Parameters
|Name|Type|Description|
|---|---|---|
|hObject|HANDLE|The symbol definition, plug-in object style, or plug-in object.|

## Returns
Whether the use wall cut plane setting of the symbol definition, plug-in object style, or plug-in object is by style.
