# GetDVSetElemName

## Description
Gets the name of the Nth index data visualization element within the data visualization set setName

```pascal
FUNCTION GetDVSetElemName(
				setName : STRING;
				index   : INTEGER) : STRING;
```

```python
def vs.GetDVSetElemName(setName, index):
    return STRING
```
